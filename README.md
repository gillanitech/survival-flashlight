# Survival Flashlight

Survival Flashlight is an Android utility that combines an LED flashlight with SOS and strobe modes, a front light, battery diagnostics, and weather information. This repository contains its official website.

## Features
- LED Flashlight
- SOS Mode
- Strobe Light
- Front Light
- Battery Diagnostics
- Weather Information

**Android package:** `com.survival.flashlight`

**Official Website:** https://gillanitech.github.io/survival-flashlight/

**Privacy Policy:** https://gillanitech.github.io/survival-flashlight-privacy/

## Technology
HTML5 · CSS3 · JavaScript · GitHub Pages (no build step, no dependencies)

## Deploy
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Placeholders to replace
- **Google Play URL and support email:** edit `CONFIG` at the top of `script.js`.
- **Screenshots:** drop images in `assets/screenshots/` and swap them into the `.phone__screen` block in `index.html` (see the comment there).
- **Social preview image:** add `assets/images/og-image.png` (1200×630).
- **App icon:** replace `assets/icons/favicon.svg` (and add a PNG if desired).
